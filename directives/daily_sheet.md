# Daily sheet

## Purpose

Keep the day on one page: ONE main thing, up to 5 tasks with time blocks, a wins
line. A second backlog is a failure — state lives in the project files.

## When to use

Every session start. If `TODAY.md` is missing or stale (not today's date),
regenerate it.

## How

1. Run `python execution/example_new_day.py` (or ask the human to).
2. Propose the ONE main thing + top 5 tasks with time blocks.
3. Human confirms or edits.
4. End of day: fill the wins line.

## Bounds

- Never create a second backlog elsewhere.
- This is a planning page, not a history — old days get archived or overwritten.
