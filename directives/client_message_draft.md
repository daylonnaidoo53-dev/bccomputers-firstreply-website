# Client message drafts

## Purpose

Prepare every client-facing message as a DRAFT. The human sends. Always.

## When to use

Any email, DM, or message to a client, customer, or prospect.

## How

1. Draft in `drafts/YYYY-MM-DD.md` (one dated file per day, append-only).
2. Keep it short and in the human's voice — no agent jargon, no jargon walls.
3. Show the draft and wait. "The plan is fine" is not "send it" — sending is its
   own explicit approval.

## Bounds

- Never send. Never schedule a send. Never automate a send.
- Never edit a sent message retroactively.
